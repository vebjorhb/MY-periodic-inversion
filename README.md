# Moreau–Yosida-based Kohn–Sham Inversion for Periodic Systems
Supporting information, including the structures, raw data, and computational scripts for the article:

Vebjørn H. Bakkestuen, Michael F. Herbst, Vegard Falmår, Markus Penz, and Andre Laestadius 
*Moreau–Yosida-based Kohn–Sham Inversion for Periodic Systems*

The code found in this repository has been used to run all calulations and produce all plots described in the above article. 
The implementation relies on the Julia software package [DFTK](https://github.com/JuliaMolSim/DFTK.jl/)

## Execution and Plotting
The implementation was made in [Julia version 1.12.4](https://julialang.org/downloads/) using DFTK version 0.7.20. 

To instantiate the correct versions of the necessary packages:
```
julia --project=@. -e "import Pkg; Pkg.instantiate()"  # Install dependencies
```

### Bulk Materials

A reference calculation for a system is run by calling the corresponding script, e.g.,
```
julia --project=. reference_silicon_Ecut_45_kgrid_10.jl > inversion_silicon_Ecut_45_kgrid_10.log
```
The inversion can subsequently be called as 
```
julia --project=. -t32 inversion_silicon_Ecut_45_kgrid_10.jl > inversion_silicon_Ecut_45_kgrid_10.log
```
Please be aware that generating the data, in particular the data for the inversion requires some resources. The caluculations are best performed on a cluster node, where some calculations requires significant memory during (up to about 100 GB RAM). 

The preprocessed data used for this publication can be found in [results](https://github.com/vebjorhb/MY-periodic-inversion/tree/main/results). All plots can be generated by calling 
```
julia --project=. -e 'include("analysis.jl"); main()'
```

### The Gross–Pitaevskii Equation
All files specific to the calculations for the one-dimensional Gross–Pitaevskii equation can be found in files starting with `GP_`. Due to the reduced computational cost in one dimension, all calculations for the Gross–Pitaevskii equation can be performed on a laptop in times on the order of minutes. The reference calculations and the inversion using the optical lattice potential (as shown in the article) are called by 
```
julia --project=. -e 'include("GP_run.jl"); main()'
```
which also generates the plots.  

The timing calculation is performed by calling
```
julia --project=. -e 'include("GP_timing_proximal_alg.jl"); main()'
```
which times the various methods by averaging over 5 runs. Please be aware that to avoid effects of the precompilation in Julia, one additional run is performed per method before the averaging.
